# Relight Studio AI 0.1.1 (public beta)

A visual update: Relight Studio AI has a new logo, built in the same system as its parent brand,
[Lumora Studio](https://cesaressau21.github.io/lumora-studio/). The editor, its features and its
limitations are the same as in [0.1.0](https://github.com/cesaressau21/relight-studio-ai/releases/tag/v0.1.0-beta).

## What's new

- **New logo.** A subject and a light that orbits it, the way you drag lights around a photo in
  the app. Flat and minimal, it stays readable down to 16 px.
- **Everywhere in the app.** The new mark is in the title bar, the window and taskbar icon, the
  Start menu and desktop shortcuts, and the setup.
- **Logo kit.** SVG and PNG versions for dark and light backgrounds, in color and in one color,
  are in [`assets/brand`](https://github.com/cesaressau21/relight-studio-ai/tree/main/assets/brand),
  with usage notes.

## Download and install

1. Download **`RelightStudioAI-0.1.1-beta-setup.exe`** (about 2 MB) below and run it. No
   administrator rights are needed. If Windows SmartScreen warns about an unknown publisher (the
   setup is not code-signed yet), choose **More info → Run anyway**.
2. **Updating from 0.1.0:** run the new setup over the existing installation. Python, PyTorch and
   the other components have not changed, so nothing large is downloaded again; it takes a few
   seconds.
3. **New installation:** setup downloads its components with a window showing progress, so keep
   the computer online. That is about 3 GB with an NVIDIA GPU (CUDA 13.0 for GTX 16 / RTX 20 and
   newer with driver 580+, CUDA 12.6 for older NVIDIA GPUs) or about 0.5 GB without one (CPU). On
   first launch the app downloads its two AI models (~200 MB).

Windows may keep showing the old icon on existing shortcuts for a while, until it refreshes its
icon cache. Signing out and back in refreshes it.

**Requirements:** Windows 10 or 11 (64-bit). With an NVIDIA GPU the installed app takes about
4 GB, and setup needs about 7 GB free while it runs.

## Known limitations

Unchanged from 0.1.0: the depth is relative and estimated from one photo, there are only two
layers (subject and background), removing the original light is partial, and shadows are
screen-space. The full list is in
[docs/STATUS.md](https://github.com/cesaressau21/relight-studio-ai/blob/main/docs/STATUS.md).
